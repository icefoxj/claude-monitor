claude-monitor

A desk status light for Claude Code on the M5Stack AtomS3R. Firmware __VERSION__.

Plug the AtomS3R into a USB-C cable and click the button. Works in Chrome and Edge (Web Serial); Firefox and Safari cannot talk to serial ports.

This browser has no Web Serial: use Chrome or Edge, or flash with esptool as described in the README. This page must be served over HTTPS for Web Serial to work.
  1. A board that has never been flashed may need download mode: hold the side reset button for about 2 seconds before clicking, until the screen goes dark.
  2. On Windows, if the claude-monitor daemon is already running it owns the port. Free it first: Invoke-RestMethod -Method Post http://localhost:47831/release, then flash within two minutes.
  3. When the browser asks, pick the port named USB Serial Device or USB JTAG/serial debug unit.
  4. After the reset the screen shows a green check. Next: set up the daemon and the Claude Code hooks, see the README.

The files written here are the bootloader, partition table and app attached to the GitHub release, each at its own offset, so a calibration stored on the device survives an update. Tick Erase device in the dialog to start from a blank flash instead. Sources, protocol and hook mapping: github.com/icefoxj/claude-monitor.
